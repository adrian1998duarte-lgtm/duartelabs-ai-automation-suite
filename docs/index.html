Frequently Asked Questions

Common questions about WADesk and DuarteLabs Apify Actors.

What is WADesk and how do I install it? ▼
WADesk is an official Chrome Web Store productivity extension for WhatsApp Web. You can install it with 1 click directly from the Chrome Web Store. It allows you to message unsaved numbers, use instant response templates, tag leads in a visual CRM, and export group numbers.
How does the pay-per-result pricing work for Apify Actors? ▼
There are zero monthly subscription fees. You only pay for what you extract (e.g. $0.0009 to $0.0025 per item). Apify gives all accounts $5.00 in free monthly credits, allowing you to test and run thousands of leads completely free.
How does DuarteLabs connect with WADesk? ▼
When you run DuarteLabs B2B or Google Maps scrapers, each lead includes a pre-calculated WhatsApp direct link. Clicking this link opens WhatsApp Web, where WADesk automatically loads your canned response script, tags the lead, and helps you close the prospect immediately.
Can I use DuarteLabs Actors inside Claude Desktop or Cursor? ▼
Yes. We provide native Model Context Protocol (MCP) configuration. Just copy the JSON snippet from our Developers section into your Claude or Cursor settings with your Apify token, and you can invoke any scraper directly inside your AI chat.
