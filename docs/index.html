Quick Integrations

Claude Desktop / Cursor (MCP) 
{
  "mcpServers": {
    "duartelabs": {
      "command": "npx",
      "args": [
        "-y",
        "@apify/actors-mcp-server",
        "--actors",
        "duartelabs/google-maps-business-email-whatsapp-enricher"
      ],
      "env": {
        "APIFY_TOKEN": "YOUR_APIFY_API_TOKEN"
      }
    }
  }
}
Clay.com / cURL HTTP API 
curl -X POST "https://api.apify.com/v2/acts/duartelabs~b2b-lead-whatsapp-pixel-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": [{"url": "https://example.com"}], "language": "en"}'
