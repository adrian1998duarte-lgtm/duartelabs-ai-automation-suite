Frequently Asked Questions

Everything you need to know about running and integrating DuarteLabs Actors.

Do I need coding experience to use these Actors? ▼
No! You can run any Actor directly from the Apify Web Console with a simple user-friendly form, or import our ready-made n8n workflows without writing a single line of code.
How does the pay-per-result pricing work? ▼
There are zero monthly subscription fees. You only pay for the exact data you extract (e.g. $0.0009 to $0.0015 per item). Apify gives all accounts $5.00 in free monthly usage credits, allowing you to run thousands of test queries completely free.
Can I connect these tools to Claude Desktop or Cursor? ▼
Yes. We provide native Model Context Protocol (MCP) configuration. Just copy the JSON snippet from our Developers section into your Claude or Cursor settings, insert your Apify API token, and you can invoke any scraper directly inside your chat.
Is my Apify API Token secure? ▼
100% secure. You maintain full ownership of your credentials. Requests are authenticated directly with Apify's secure cloud endpoints. Your tokens are never stored, logged, or shared.
